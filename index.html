Xtream UI Pro Connectors
Getting started Connectors Verify & update Contribute GitHub

Sell IPTV lines from the system you already use

Connectors let a reseller of an Xtream UI Pro panel sell lines and sub-reseller accounts from their own billing system, shop or ERP. A paid order creates the line on the panel, and suspension, renewal and cancellation follow automatically. You keep your own prices and payment gateway.

Choose a connector How it works Source on GitHub

Early versions: not yet proven in real use

These connectors are new. Most have only been run against a panel through a stand-in for the host system, or with only their core tested; none has yet been through real orders and real customers over time. Think it over before you use one in production.

  • Read the How it was tested box of the connector you pick: it says exactly what has and has not been run.
  • Install it on a test copy of your system first and run a full cycle there: order, renewal, suspension and cancellation.
  • Start with a small amount of credits on the reseller account the connector uses, and watch the first orders.
  • The connectors are provided as they are, without warranty (MIT license). Report what goes wrong on GitHub.

Getting started

Every connector talks to the panel through the Reseller API with your own API key. It never sees the panel's admin side and adds no payment step of its own.

  1. Get your API details

    Sign in to the panel with the reseller account the orders are charged to. Its Connectors page shows the API address and the link that creates your API key.

  2. Download and install

    Pick your system below, download the archive and follow its install steps. Each archive also holds a README with every option.

  3. Connect and test

    Enter the API address and the API key in the connector's settings and run its connection test.

  4. Sell

    Map your products to panel packages. New lines, renewals and sub-reseller accounts are paid from the credits of your reseller account, so keep enough credits.

Module for Blesta: a paid order creates a line or a sub-reseller account, and renewal, suspension and cancellation in Blesta are carried out on the panel.

How it was testedEvery module function was run against a panel through a stand-in for Blesta. It has not yet run inside a licensed Blesta.

  1. Upload the components folder of the archive into the root folder of Blesta, so that components/modules/xtreampro/ exists.

  5. Create a package with the module Xtream UI Pro and choose what it sells: a line with its package, or a sub-reseller account with its credits.

  4. In Invoice Ninja open Settings → Account Management → Webhooks and add webhooks for the invoice events listed in the README, pointing at https://your-bridge/hook/invoiceninja, with the custom header from config.php as the shared secret.
  5. Run php bin/bridge.php check to test the configuration, and schedule php bin/bridge.php retry every few minutes to repeat what failed.

Verify & update

Check a download

Every archive carries its version in its name. Compare it with the checksum list before you install it:

curl -O https://plugins.xtream-ui.pro/SHA256SUMS
sha256sum -c --ignore-missing SHA256SUMS

Scripts and tools can read versions.json: the current version, file and checksum of every connector.

Update a connector

  • Read the connector's CHANGELOG (next to its README) for what changed.
  • Install the new archive over the old one, the same way you installed it.
  • Run the connection test again afterwards.

The same archives are also on your panel's Connectors page.

Contribute

Report a problem

Open an issue with the connector and its version, your system's version, what you did and the error from its module log. Remove API keys, passwords and customer data before you paste a log.

Improve a connector

The connectors are open source under the MIT license. Fork the repository, change one connector per pull request and say how you tested it. See CONTRIBUTING.md.
